# NetPractice Plus 🌐

## Overview
**NetPractice Plus** is an advanced, enhanced version of the classic NetPractice project, designed to master computer networking concepts, routing principles, and network topology design through interactive and engaging levels.

## Features
- **Multi-Level Progression:** Features a comprehensive set of levels scaling from networking fundamentals to advanced topologies.
- **Flexible Configuration:** Utilizes modular JSON configuration files for each level, ensuring easy maintenance and scalability.
- **Interactive Web Interface:** Built with responsive front-end elements to visually render hosts, routers, switches, and internet components.

## Project Structure
```text
netpractice_plus/
├── netpractice_configs/   # Level configurations and definitions (JSON)
├── netpractice_plus/      # Front-end assets, HTML views, JS logic, CSS styles, and graphics
└── run.sh                 # Quick execution and startup script
```
